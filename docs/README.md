# Peculiar Librarian

## Finance Semantic Knowledge Hub

Peculiar Librarian is a finance-first semantic knowledge repository built using W3C Semantic Web standards.

Its purpose is to curate, validate, and publish high-quality financial knowledge as interoperable semantic assets.

The repository is intentionally domain-focused.

It is **not** a semantic kernel.

It is **not** a workflow engine.

It is **not** a reasoning framework.

It is a canonical finance knowledge collection.

---

# Mission

Transform financial research into structured semantic knowledge.

Every piece of knowledge is represented using open standards.

Every semantic distinction is explicit.

Every published artifact is machine-readable.

---

# Guiding Principles

- Finance is the only domain modeled in this repository.
- Knowledge is the primary asset.
- Semantics are explicit.
- Validation protects integrity.
- Publication enables interoperability.
- Infrastructure remains minimal.
- Every file must have a clear purpose.

---

# Semantic Pipeline

Every finance collection follows the same pipeline.

```
Research
    │
    ▼
OWL
    │
    ▼
RDF
    │
    ▼
SKOS
    │
    ▼
SHACL
    │
    ▼
SPARQL
    │
    ▼
JSON-LD
```

Each stage has one responsibility.

```

```

---

# Standards

| Layer | Standard |
|--------|----------|
| Ontology | OWL |
| Knowledge | RDF |
| Taxonomy | SKOS |
| Validation | SHACL |
| Queries | SPARQL |
| Publication | JSON-LD |

# Scope

This repository models financial knowledge.

Examples include:

- Companies
- Financial Statements
- Financial Metrics
- Corporate Actions
- Dividends
- Earnings
- Cash Flows
- Assets
- Liabilities
- Equity
- Provenance
- Citations

---

# Non-Goals

This repository does not implement:

- Workflow orchestration
- Generic semantic kernels
- Execution runtimes
- Multi-domain reasoning engines
- Agent frameworks

Those belong in separate projects.

---

# Long-Term Vision

Peculiar Librarian becomes a reference-quality finance semantic collection.

Every future financial entity should be representable using the same semantic architecture.

Knowledge evolves.

The semantic pipeline remains stable.
