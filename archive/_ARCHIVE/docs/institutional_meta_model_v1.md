# Institutional Meta-Model
Version 1.0.0

---

# Purpose

The Institutional Meta-Model defines the universal conceptual objects that
exist throughout the Peculiar Ecosystem.

Every Practice Area SHALL specialize these concepts rather than redefine them.

The Meta-Model provides a common semantic language across all domains.

# Object Responsibilities

Institution

Defines organisational context.

Practice Area

Defines professional scope.

Engagement

Defines analytical boundary.

Question

Defines investigative intent.

Evidence

Establishes factual support.

Finding

Represents governed interpretation.

Risk

Represents potential negative consequence.

Opportunity

Represents potential positive consequence.

Recommendation

Represents a justified strategic option.

Decision

Represents executive authority.

Outcome

Represents realised institutional impact.

Knowledge Asset

Represents reusable institutional knowledge.

---

# Constitutional Rule

Every object SHALL possess:

Identity

Context

Provenance

Relationships

Validation status

Lifecycle

---

# Semantic Rule

No object exists independently.

Meaning emerges through relationships.

---

# Executive Rule

Reports SHALL be assembled from constitutional objects rather than authored
from unstructured text.
