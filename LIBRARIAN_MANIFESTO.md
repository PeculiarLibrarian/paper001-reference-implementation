# The Peculiar Librarian Manifesto

## We do not build software.

We build libraries.

A library is not defined by its building.

A library is defined by its knowledge.

Everything else exists to preserve, organize, and make that knowledge discoverable.

---

## Knowledge belongs in the collections.

Ontologies define meaning.

Taxonomies define classification.

Shapes define integrity.

Queries define retrieval.

These are not implementation details.

They are the system.

---

## Python is infrastructure.

Python is the building.

It provides shelves, corridors, lighting, catalogues, storage, and utilities.

It is essential.

But the building is never mistaken for the knowledge it protects.

Infrastructure must never become the source of truth.

---

## Collections are the product.

Software is infrastructure.

Collections are the product.

A collection is a curated body of governed knowledge.

Every collection contains its own ontology, taxonomy, shapes, queries, and instances.

The librarian does not create knowledge.

The librarian curates collections.

New domains are introduced by curating new collections, never by rewriting infrastructure.

Infrastructure should stabilize.

Collections should evolve.

The library grows through knowledge, not through code.

---

## Every collection has a custodian.

Each schema has a dedicated manager.

A manager understands one collection completely.

It discovers.

It loads.

It parses.

It validates.

It exposes.

It does not reason beyond its collection.

It does not interfere with another collection.

Its responsibility ends at stewardship.

---

## The Peculiar Librarian is the orchestrator.

The librarian owns no knowledge.

The librarian writes no ontology.

The librarian invents no taxonomy.

The librarian performs no reasoning.

The librarian coordinates.

It knows where every collection resides.

It assembles them into a coherent semantic environment.

Its authority comes from organization, never ownership.

---

## Runtime is a reading room.

Every request opens a reading session.

The librarian prepares the room.

The necessary collections are brought together.

Validation is completed.

Only then does research begin.

---

## Reasoning belongs to the researcher.

Inference is not librarianship.

Decision-making is not librarianship.

Capability matching is not librarianship.

Those belong to semantic engines, agents, and researchers operating inside the reading room prepared by the librarian.

---

## The catalogue is sacred.

Discovery must never rely on hidden assumptions.

Every collection must be discoverable.

Every artifact must be locatable.

Every relationship must be explicit.

Nothing is remembered that can be described.

Nothing is guessed that can be modeled.

---

## Semantics before implementation.

Implementation changes.

Knowledge endures.

Programming languages evolve.

Frameworks disappear.

Infrastructure is replaced.

The library remains.

The schemas remain.

Meaning remains.

---

## Separation is strength.

Knowledge is not infrastructure.

Infrastructure is not orchestration.

Orchestration is not reasoning.

Reasoning is not knowledge.

Every layer exists for a single purpose.

A system becomes understandable when responsibilities are not confused.

---

## We preserve knowledge.

We organize knowledge.

We expose knowledge.

We never bury knowledge inside code.

We build systems that can outlive their infrastructure.

We are librarians before we are programmers.

We build libraries that machines can read, humans can understand, and future generations can extend.

**This is the way of the Peculiar Librarian.**
